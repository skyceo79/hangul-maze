# 한글 미로 — 최종 기획안 (확정)

초등학교 저학년용 한글 자모 조합 게임. 팩맨처럼 미로를 돌아다니며 단어의 자음·모음을 **순서대로** 먹어서 단어를 완성한다.

- 1차: 웹 브라우저에서 테스트 → 2차: 안드로이드 태블릿 (매스 갤럭시와 같은 방식)
- 분위기: 매스 갤럭시처럼 밝은 파스텔 색감, 귀여운 캐릭터

## 1. 기본 진행

- 6단계 × 20문제. 단어 묶음 3개를 **글자 단계 → 그림 단계** 순서로 두 번씩 쓴다

| 단계 | 단어 묶음 | 화면에 보이는 것 |
|---|---|---|
| 1 | A. 받침 없는 단어 | 글자 + 그림 (예: 🌳 **나무**) |
| 2 | A. 받침 없는 단어 | 그림만 (🌳 + 빈칸 □□) |
| 3 | B. 받침 있는 단어 | 글자 + 그림 |
| 4 | B. 받침 있는 단어 | 그림만 |
| 5 | C. 복잡한 모음·쌍자음 | 글자 + 그림 |
| 6 | C. 복잡한 모음·쌍자음 | 그림만 |

- 단어 하나 = 미로 한 판. 단어를 완성하면 다음 문제로
- 20문제를 모두 완성하면 다음 단계가 열린다
- **문제 순서는 매번 랜덤.** 단, 세 글자 "보스 단어" 2개는 항상 19·20번에 나온다
- 그림 단계: 몇 글자인지 빈칸(□□)으로 보여 준다. 단어를 완성하면 글자가 나타난다

## 2. 글자 먹기 규칙

- 미로 곳곳에 자음·모음 타일이 놓여 있다. 작은 점(팩맨 기본 먹이)은 없다
- **차례가 된 글자**를 먹으면 → 가운데 단어 칸에 들어가며 글자가 조합되는 모습을 보여 준다
  - 예: `ㄱ` → `게` → `게ㅇ` → `게이` → `게임`
- **방해 글자**(단어에 없는 글자)는 먹어도 된다. 벌점 없음
- **아직 차례가 아닌 정답 글자**는 먹어지지 않는다. 살짝 흔들리며 "아직이야!" 표시
- 같은 글자가 두 번 필요하면(예: 바다의 ㅏ) 미로에 그만큼 놓아 둔다
- **복잡한 모음은 나눠서 먹는다**: ㅘ=ㅗ+ㅏ, ㅝ=ㅜ+ㅓ, ㅙ=ㅗ+ㅐ, ㅚ=ㅗ+ㅣ, ㅟ=ㅜ+ㅣ, ㅢ=ㅡ+ㅣ
  - 예: `ㄱ` → `고` → `과` → `과ㅈ` → `과자`
  - ㅐ, ㅔ, ㅖ와 쌍자음(ㄲ ㄸ ㅃ ㅆ ㅉ)은 타일 하나
- 단어 완성 → 단어를 소리로 읽어 주고 축하 효과

## 3. 반짝이 힌트

- 각 단계의 **1번, 2번 문제만** 다음에 먹을 글자가 반짝인다 → 아이가 규칙(순서대로 먹기)을 스스로 파악하도록
- 3번 문제부터는 반짝이지 않는다
- 설정 → **힌트 켜기 / 끄기** (끄면 1·2번 문제도 반짝이지 않음)

### 💡 글자 보기 (그림 단계: 2·4·6단계)

- 버튼을 누르면 목표 단어를 2초 동안 글자로 보여 준다
- 단계마다 5번, 다음 단계에서 다시 채워짐

## 4. 유령

- 유령 2~3마리, 아이들용으로 느리게 움직인다 (단계가 올라가면 조금 빨라짐)
- 유령에게 잡히면 → 팩맨이 시작 위치로 돌아간다. **모은 글자는 그대로 유지**
- 게임 오버 없음
- ⭐ 별사탕(미로 구석 2~4개): 먹으면 잠깐 유령이 파랗게 변해 도망가고, 잡으면 보너스 점수

## 5. 조작 (태블릿)

- 화면 스와이프로 방향 바꾸기 + 방향 버튼(설정에서 위치 이동·좌우 반전 가능, 매스 갤럭시와 동일)
- PC 테스트용: 방향키

## 6. 별점

- 단계가 끝나면 20문제 동안 유령에게 잡힌 횟수로 별점
  - 3번 이하 ⭐⭐⭐ / 8번 이하 ⭐⭐ / 그 외 ⭐
