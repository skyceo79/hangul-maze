# 한글 미로

초등 저학년용 한글 자모 조합 미로 게임입니다. 기획 내용은 [docs/기획안.md](docs/기획안.md)에 있습니다.

## 실행 (PC 브라우저)

설치할 패키지가 없습니다. Node.js만 있으면 됩니다.

```bash
node hangul-maze/serve.js
```

브라우저에서 http://localhost:5181 을 엽니다.
PC 조작: 방향키로 이동, H 키로 💡 글자 보기(그림 단계).

## 파일 구조

| 파일 | 내용 |
|---|---|
| `js/words.js` | 단어 목록(묶음 A·B·C)과 6단계 규칙 (유령 수·속도, 방해 글자 수) — 단어를 바꾸려면 여기 |
| `js/hangul.js` | 단어 → 자모 나누기(ㅘ = ㅗ + ㅏ), 먹은 만큼 글자 조합하기 |
| `js/maze.js` | 미로 모양 4가지 (`#` 벽, `P` 팩맨, `G` 유령, `*` 별사탕 자리) |
| `js/game.js` | 게임 진행 (글자 먹기, 유령, 별사탕, 20문제 흐름) |
| `js/art.js` | 미로·글자 타일·팩맨·유령 그림 |
| `js/controls.js` | 방향키, 스와이프, 위치 바꾸기 |
| `js/main.js` | 화면 전환, 프로필, 위쪽 단어 표시, 팝업 |
| `js/audio.js` | 효과음(합성음), 글자 읽어 주기 |
| `js/storage.js` | 프로필·별 저장 (기기 안 localStorage) |
| `sw.js`, `manifest.webmanifest` | 태블릿 홈 화면 설치·오프라인 실행 |

미로를 새로 그릴 때는 막다른 길이 없게(모든 길 칸이 2방향 이상 열려 있게) 만듭니다.

`sw.js`의 `VERSION`은 파일을 고친 뒤 배포할 때마다 올려야 태블릿에 새 버전이 반영됩니다.
